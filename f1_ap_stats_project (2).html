Unit 1

Research Question & Variables

Research Question: Is starting from pole position (P1 on the grid) statistically associated with a higher probability of winning an F1 Grand Prix compared to starting from any other position?

Explanatory Variable (X): Grid starting position — categorical: Pole (P1) vs. Non-pole (P2–P20+). Also quantitative (1–20) for regression.

Response Variable (Y): Race outcome — binary categorical: Win vs. No Win.

Population: All F1 World Championship Grand Prix races (1950–2024). N = 1,096 races with pole data. ~21,920 total individual race starts analyzed.

Unit 2

Probability & Simulation

Sample Space & Events

S = {all F1 race starts 1950–2024}. Event A: Pole start. Event B: Race win.

P(A) = 1/20 = 0.05    P(B) = 1/20 = 0.05
P(B | A) = 478/1,096 = 0.4361    P(B | Aᶜ) = 618/20,824 ≈ 0.0297
Visual 2A — Probability Tree Diagram: Pole Start → Race Outcome
Visual 2B — Simulation: Distribution of Pole Win Rate Under H₀ (null = no advantage, p=0.05) vs. Observed 43.6%

Conditional Probability

P(Win | Pole) = 478/1,096 ≈ 0.4361

Given a pole start: 43.61% chance of winning — 14.7× higher than non-pole starters.

Independence Check

Events are independent if P(B|A) = P(B).

P(Win) = 0.05 ≠ P(Win|Pole) = 0.4361

NOT independent. Grid position dramatically changes the win probability.

General Multiplication Rule

P(Pole AND Win) = P(Pole) × P(Win|Pole) = (1/20) × 0.4361 ≈ 0.0218
P(Non-Pole AND Win) = (19/20) × 0.0297 ≈ 0.0282
P(Win) = 0.0218 + 0.0282 = 0.0500 ✓

Complement Rule

P(NOT winning from pole) = 1 − 0.4361 = 0.5639

Even from pole, a 56.4% chance of not winning — a major advantage, not a guarantee.

Bayes' Theorem

Given a race was won, P(winner started from pole)?

P(Pole|Win) = (0.4361 × 0.05) / 0.05 = 0.4361

43.6% of all race winners started from pole.

Random Variables & Probability Distributions

Binomial Random Variable — BINS Conditions

Let X = wins in next n races, all from pole. ✅ Binary (Win/No Win) ✅ Independent races ✅ N fixed in advance ✅ Same p = 0.4361 each race.

X ~ B(n, p) where p = 0.4361
Visual 3A — Binomial PMF: X ~ B(10, 0.4361) — Probability of Each Win Count from 10 Pole Starts
Visual 3B — Normal Approximation to B(24, 0.4361): Normal Curve Overlaid on Binomial Histogram

B(10, 0.4361): Mean, Variance, SD

μ_X = np = 10 × 0.4361 = 4.361 wins
σ²_X = np(1−p) = 2.460
σ_X = √2.460 = 1.569 wins

vs. Non-pole B(10, 0.0297): μ = 0.297, σ = 0.537

Geometric: Wait for First Win from Pole

Y = pole starts until first win. Y ~ Geom(0.4361).

μ_Y = 1/p = 1/0.4361 ≈ 2.29 starts
P(Win 1st try) = 0.4361
P(Win by 3rd try) ≈ 0.821

Sampling Distribution of p̂

μ_p̂ = p = 0.4361    σ_p̂ = √[p(1−p)/n] = √[0.4361×0.5639/1096] = 0.01497

Conditions: np = 478 ≥ 10 ✅   n(1−p) = 618 ≥ 10 ✅

p̂ ~ N(0.4361, 0.01497) approximately

For samples of n=1,096, pole win rates cluster tightly around 43.6%. 95% of samples fall within ±3% of the true proportion.

Statistical Inference

Visual 4A — 95% Confidence Interval for Pole Win Rate vs. Null Baseline

One-Proportion Z-Interval for Pole Win Rate

Parameter: p = true proportion of F1 races won from pole.   p̂ = 478/1,096 = 0.4361

Conditions: ✅ Random ✅ Normal (np̂=478≥10, n(1−p̂)=618≥10) ✅ Independent

95% CI: 0.4361 ± 1.96 × 0.01497 = 0.4361 ± 0.02934

Interpretation

We are 95% confident the true pole win rate is between 40.7% and 46.6%. This interval does NOT contain 5% (the null baseline), providing strong evidence for the pole advantage.

Complete R Script

########################################################
# F1 POLE POSITION WIN RATE — AP STATS PROJECT
# Units 1-4 | 2025-26 CED
########################################################

# ── DATA SETUP ──────────────────────────────────────
grid_data <- data.frame(
  position = 1:10,
  wins     = c(478,217,123,87,58,38,25,18,11,8),
  races    = rep(1096, 10)
)
grid_data$win_rate <- grid_data$wins / grid_data$races

# ── UNIT 1 ──────────────────────────────────────────
winner_pos <- rep(grid_data$position, grid_data$wins)
summary(winner_pos)   # 5-number summary
cat("Mean:", mean(winner_pos), "SD:", sd(winner_pos),
    "IQR:", IQR(winner_pos), "\n")
r_lin <- cor(grid_data$position, grid_data$win_rate)
r_log <- cor(log(grid_data$position), grid_data$win_rate)
cat("r (linear):", r_lin, "  r (log-transformed):", r_log, "\n")

# Scatter + log-linearized plot
library(ggplot2)
ggplot(grid_data, aes(position, win_rate)) +
  geom_point(color="#E8002D", size=3) +
  stat_smooth(method="nls", formula=y~a*x^b,
    method.args=list(start=list(a=0.5,b=-1)), se=FALSE,
    color="white") +
  labs(title="F1 Win Rate by Grid Position",
       x="Grid Position", y="Win Rate") + theme_dark()

# Boxplot of winner starting positions
boxplot(winner_pos, horizontal=TRUE,
        main="Starting Position of Race Winners",
        xlab="Grid Position", col="#E8002D")

# ── UNIT 2 ──────────────────────────────────────────
p_win_pole    <- 478/1096
p_win_nonpole <- 618/20824
cat("P(Win|Pole):", p_win_pole, "\n")
cat("P(Win|Non-Pole):", p_win_nonpole, "\n")
cat("Relative Risk:", p_win_pole/p_win_nonpole, "\n")
cat("P(Pole AND Win):", (1/20) * p_win_pole, "\n")

# Simulation under null (no advantage)
set.seed(2025)
sims <- replicate(10000,
  mean(sample(1:20, 1096, replace=TRUE) == 1))
cat("Null sim mean:", mean(sims),
    "SD:", sd(sims), "\n")
cat("P-value (sim ≥ 0.4361):",
    mean(sims >= 0.4361), "\n")

# ── UNIT 3 ──────────────────────────────────────────
p <- 478/1096; n <- 10
binom_tbl <- data.frame(
  k   = 0:10,
  pmf = dbinom(0:10, n, p),
  cdf = pbinom(0:10, n, p))
print(round(binom_tbl, 4))
cat("Mean:", n*p, "Var:", n*p*(1-p),
    "SD:", sqrt(n*p*(1-p)), "\n")

# Geometric
cat("E(Y) geometric:", 1/p, "\n")
cat("P(win ≤3 attempts):", pgeom(2, p), "\n")

# Normal approximation B(24,p)
mu24 <- 24*p; sd24 <- sqrt(24*p*(1-p))
z12  <- (12-mu24)/sd24
cat("P(X≥12) Normal:", pnorm(z12, lower.tail=FALSE),
    "Exact:", pbinom(11,24,p,lower.tail=FALSE), "\n")

# ── UNIT 4 ──────────────────────────────────────────
# 1. One-proportion CI
ci <- prop.test(478, 1096, conf.level=0.95, correct=FALSE)
cat("95% CI:", ci$conf.int, "\n")

# 2. Two-proportion Z-test
tp <- prop.test(c(478,618), c(1096,20824),
               alternative="greater", correct=FALSE)
cat("z=", sqrt(tp$statistic), "p=", tp$p.value, "\n")

# Manual z
p1h <- 478/1096; p2h <- 618/20824
pp  <- (478+618)/(1096+20824)
se  <- sqrt(pp*(1-pp)*(1/1096+1/20824))
cat("Manual z:", (p1h-p2h)/se, "\n")

# 3. Chi-square
mat <- matrix(c(478,618, 217,879, 123,973,
                87,1009, 58,1038),
              nrow=5, byrow=TRUE)
cs <- chisq.test(mat, correct=FALSE)
cat("Chi2:", cs$statistic, "df:", cs$parameter,
    "p:", cs$p.value, "\n")

# 4. Regression inference (log transform)
grid_data$log_pos <- log(grid_data$position)
mod <- lm(win_rate ~ log_pos, data=grid_data)
summary(mod)
confint(mod, level=0.95)

# Residual plot
plot(fitted(mod), residuals(mod),
     main="Residual Plot", xlab="Fitted", ylab="Residuals")
abline(h=0, col="red", lty=2)
